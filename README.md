# 🌍 Earth–Moon–Sun System Simulator

3D веб-симулятор системы **Земля–Луна–Солнце** с визуализацией движения небесных тел и возможностью наблюдать **солнечные и лунные затмения**.

Проект разработан в рамках IT-проекта (команда №46).

---

# 📌 Описание проекта

Программа моделирует движение **Солнца, Земли и Луны** в трёхмерном пространстве.

Функциональность симулятора:

* визуализация системы **Солнце–Земля–Луна**
* отображение орбит небесных тел
* управление временем симуляции
* наблюдение **солнечных и лунных затмений**
* отображение освещения и теней

Проект предназначен для образовательных целей и демонстрации астрономических явлений.

# 🚀 Запуск проекта

## 1. Клонировать репозиторий

```bash
git clone https://github.com/earth-moon-sun-simulator/earth-moon-sun-web.git
```

Перейти в папку проекта:

```bash
cd earth-moon-sun-web
```

---

## 2. Переключиться на ветку разработки

```bash
git checkout dev
```

---

## 3. Установить зависимости

```bash
npm install
```

---

## 4. Запустить сервер разработки

```bash
npm run dev
```

После запуска откройте:

```
http://localhost:5173
```


```bash
git checkout dev
git pull
```

Пример:

```bash

```

### После завершения работы

```bash

```

После этого создаётся **Pull Request в ветку `dev`**.
